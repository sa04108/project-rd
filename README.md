# project-rd

Godot/GDScript로 만드는 세로 화면의 오프라인 타워 디펜스 게임입니다. 골드로 용병을 소환하고 조합·재배치·성급 강화를 활용해 100웨이브 마왕을 처치합니다.

## 실행

`.godot-version`에 고정된 **Godot 4.7.2-stable standard**로 `project.godot`을 엽니다. Compatibility 렌더러와 720×1280 기준 화면을 사용합니다.

```bash
# Linux에서 고정 엔진과 Web 템플릿 준비
bash scripts/web-setup.sh
.godot-tools/4.7.2-stable/godot --path .
```

클라우드 GUI, Web 브라우저 실행, Android 준비는 [개발·검증 안내](docs/DEVELOPMENT.md)를 참고하세요.

## 조작과 제공 범위

- **소환**으로 무작위 1성 용병을 영입합니다. 시작 골드는 세 번의 소환 비용이며 빈칸은 왼쪽 열 위부터 채웁니다.
- 탭은 용병 정보 선택, 빈칸 탭은 선택 해제입니다. 이동·교환은 드래그로만 하며, 이때 배치 격자와 노란 안내 화살표가 나타납니다. 조합은 **조합법**에서 실행합니다.
- 배속은 **×1 → ×2 → ×3 → ×5**, 일시정지는 별도 버튼입니다. 설정을 열면 전투가 멈추고 도감·조합법·하단 창을 열면 계속 진행됩니다.
- **설정**에서 배경음악·효과음 음량을 따로 조절합니다. 전투곡은 **안개의 파수**, 일반 클릭은 탭, 성공 확인은 차임입니다. 진동은 기본 꺼짐이며 켤 때·목숨 감소·클리어 때만 울립니다.
- **저장 후 메인 메뉴 → 이어하기 → 재개**로 진행 중인 판을 복원합니다. 판 사이에 골드·용병·강화는 상속하지 않습니다.

플레이 데이터에는 용병 34종, 적 53종(일반 40·보스 10·특수 3), 조합법 28개가 등록돼 있습니다. 수치와 레시피 원본은 [data/](data/)에 있습니다. 고유 애니메이션은 아군 공격·대기 각 34행과 적 이동 53행, 총 121행/726프레임입니다. 제작 원본·런타임 연결·시각 품질 검증은 구분하며, 남은 조정·검증은 아래 단일 목록에서 관리합니다.
