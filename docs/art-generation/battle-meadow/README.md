# 맑은 초원 전장

- 사용자가 선택한 전투 시안 1번의 스타일을 바탕으로 내장 이미지 도구로 생성했다
- 북서쪽 한 성문을 출입구로 공유하며, 아래로 출발해 반시계 방향으로 돌아온다
- 출입구 문구, UI, 캐릭터, 격자는 이미지에 포함하지 않는다
- `background.source.png`는 생성 이미지의 PNG 압축본이며(가시 픽셀 보존), `assets/art/orthographic/battle-map.webp`는 품질 85로 압축한 런타임 배경이다
- 알파가 필요 없는 배경만 WebP로 변환했다. 용병·적 스프라이트의 투명도 정책과 별개다
- 하단 UI 배치는 가운데 소환, 최하단 강화·도박·특수몬스터 순서를 유지한다

## 완전한 정투영 지형 (사용자 추가 지시)

그림에 포함된 길의 원근을 그대로 사용하지 않는다. 내장 이미지 도구로 완전한 위쪽 시점의 grass/dirt 재질을 각각 생성했다. 게임은 중앙 6×6칸과 그 주변 한 칸 폭의 흙길 네 개를 정확한 축 정렬 사각형으로 그린다. 마주 보는 변의 길이와 네 변의 폭이 같고, 두 축의 텍셀 배율도 같다. 산·대기소·구름 등 주변 풍경만 기존 선택 시안의 그림을 유지한다.

`grass.source.png`, `dirt.source.png`는 새 생성 원본이고 대응 `.prompt.txt`는 실제 프롬프트다. 런타임은 품질85 WebP `meadow-grass.webp`(450,008바이트), `meadow-dirt.webp`(272,828바이트)를 사용한다. 캐릭터 스프라이트를 생성한 것이 아니므로 이 재질 프롬프트를 sprite-gen 캐릭터 프레임으로 혼동하지 않는다. 깃발 그림은 유지하고 길드 텍스트만 제거한다.

최신 적용은 정투영 중심선을 유지하면서 `terrain_blend.gdshader`에서 재질 경계를 풀잎처럼 자연스럽게 혼합한다. 지면 잡음은 위치만 사용하고 난수 상태·시간을 바꾸지 않는다. 길 폭은 용병 한 칸과 같은 78px이며 가운데 6×6칸의 468px 정사각형을 둘러싼다. 격자는 드래그 중에만 표시한다.
