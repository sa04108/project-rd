# 남은 작업과 결정 사항

## 결정이 필요한 항목

1. **난이도 목표:** 정상 조합·배치·특수몬스터를 적극 사용하는 봇은5/5 전부 목숨20으로 클리어했습니다. 초보자 첫 클리어율과 목표 실패 구간을 정하면 특수 보상·적 HP 성장·강화 가격 등 T를 조정할 수 있습니다. 30초 일정/20목숨/배속/100웨이브는 유지합니다.
2. **아트 방향:** 지금은 기능을 검증하는 공통 도형·관절 프로토타입입니다. 예시 이미지 수준의 완성 일러스트나 87종 전용 아트는 제공하지 않습니다. 애니메이션용 스프라이트를 제작하게 되면 지정된 sprite-gen 저장소를 작업자에게 전달합니다.
3. **전체 카탈로그:** 현재16용병/8일반/10보스/3특수입니다. 명세의34용병/40일반 초안에 맞출 상세 이름·레시피·역할 원본이 필요합니다. 현재 이름/레시피는 작업 기본안입니다.
4. **출시 제목/소개/스토리:** project-rd 내부 제목과 용병 길드 테마만 적용했습니다. 출시 브랜드와 서사 연출은 미확정입니다.

## 미구현 또는 미검증

- Android APK/AAB, 서명·Play Store 등록·실기기 해상도/노치/터치/앱 수명주기 QA. 데스크톱의 실제 UI 입력은 검증했지만 물리 Android 기기에서 테스트하지 않았습니다.
- Web export, GdUnit4, MCP, 외부 GPU runner, C#은 이번 MVP에 도입하지 않았습니다.
- 프로토타입 관절 드로잉을 전용 Skeleton2D/애니메이션 에셋 파이프라인으로 바꾸는 작업은 남아 있습니다. 프레임 스프라이트 시트는 없습니다.
- 합성 사운드를 실제 스피커/모바일에서 듣고 믹싱하는 QA와 접근성 확대(스크린리더, 색각 보정, 별도 입력 리맵).
- 구버전 콘텐츠로 저장된 판의 데이터 마이그레이션. 현재는 버전이 다르면 이어하기를 막고 원본을 격리합니다.
- 장시간 무한 CC로 극단적으로 많은 적이 남는 스트레스 성능 측정. 게임 규칙상 오래 남은 적을 강제로 지우지 않습니다.
- 출시용 설치 패키지와 새 클라우드 작업에서의 환경 스냅샷 복원은 별도 검증 대상입니다.

테스트 명령, 통과 수, 한계는 QA_ACCEPTANCE.md에 기록합니다. 과금·서버·영구 성장 등 명세상 범위 밖 기능은 추가하지 않았습니다.
