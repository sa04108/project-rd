# 남은 작업과 결정

결정 대기·구현 미완료·미검증 항목의 단일 목록이다. 현재 코드와 런타임 리소스에서 확인한 상태를 기록한다. 완료하면 항목을 제거하고 필요한 규칙·절차를 상시 안내서에 반영한다. 완료 이력·범위 밖 기능을 할 일로 누적하지 않는다.

## 결정 필요

| ID | 항목과 현재 상태 | 다음 행동 / 완료 기준 |
|---|---|---|
| D01 | 외부 소개·스토리의 범위는 내부 작업안이다. | 사용자가 외부에 사용할 소개·서사 범위를 확정하면 게임 문구와 규칙 문서에 반영한다. 표시 제목은 게임 규칙의 확정값을 따른다. |
| D02 | 동작 연출 줄이기 설정은 있지만 스크린리더·색각 보정·입력 재지정의 적용 범위는 확정되지 않았다. | 지원 플랫폼과 필요한 접근성 범위를 정하고, 채택한 항목의 구현·실사용 검사 기준을 정한다. |
| D03 | 로컬 다이아몬드 지갑·원장과 영구 성장 구매는 구현되어 있다. 실제 구매·소셜 계정·기기 간 동기화는 미구현이며, 로컬 지갑은 유료 재화의 신뢰 가능한 권위 저장소가 아니다. | 실제 구매나 계정 연결을 시작하기 전에 계정 제공자, 서버 권위 지갑·원장, 영수증 검증, 멱등 지급·구매 처리와 동기화 정책을 결정한다. 서버 권위 설계와 검증 기준을 확정한 뒤 구현한다. |

## 구현·제작 필요

| ID | 항목과 확인한 상태 | 다음 행동 / 완료 기준 |
|---|---|---|
| A03 | n04/n07/n11/n15/n18/n22/n26/n30/b10/b70/b90/s10/s30/s60의 보행은 걸음폭·앞뒤 다리 교대·주기 자연스러움에 보정 여지가 있다. | 루트가 필요한 원본을 보완하고 전체 주기의 접지·번갈아 딛기·루프를 직접 확인한다. 후보를 자동 채택하거나 픽셀 차이 통과를 자연스러운 보행의 근거로 삼지 않는다. |
| U01 | 첫 플레이를 안내할 초기 튜토리얼은 추후 구현한다. 전투 가이드 창은 제거했다. | 사용자와 도입 시점·안내할 조작·완료 조건을 정한 뒤 구현한다. |
| W01 | Web 저장은 로컬 파일 쓰기 뒤 IndexedDB에 비동기로 반영된다. 영속화 후 새로고침 복원은 확인했으나 일반 UI에는 완료 표시가 없고 저장 직후 탭 종료의 내구성은 확인되지 않았다. | Web export를 브라우저에서 직접 열어 저장 직후 탭 종료와 재실행을 확인한다. 영속화 완료/오류를 사용자에게 알릴 필요와 보장할 복구 범위를 정한다. |

## 검증 필요

| ID | 확인이 남은 항목 | 완료 기준 |
|---|---|---|
| Q01 | 현재 Godot 4.7.2와 최신 화면·리소스·음향을 포함한 Android APK, 물리 Android 기기 | 최신 빌드로 입력·저장·앱 중단/복귀를 재검사한다. 실제 기기의 GPU·발열·노치·해상도·제조사 종료 정책을 확인한다. 과거 4.4.1 에뮬레이터 결과를 현재 빌드나 실기기 증거로 사용하지 않는다. |
| Q02 | 최종 음악/효과음의 기기 청감·장시간 반복 피로도와 진동 | 음악/효과음 음소거, ×5 및 해금한 ×20 배속의 믹스, 끝 잡음·루프 이음새와 지원 기기의 진동 3조건을 확인한다. 음원 제작/연결은 완료됐으며 샘플 재선정 과제가 아니다. |
| Q03 | 전체 100웨이브 수동 플레이와 초보 첫 클리어율 5%·주 실패 구간 30웨이브 목표의 사람 대상 검증 | 첫 플레이 표본과 조건을 정해 도달 웨이브·실패 원인·클리어율을 기록하고 튜닝을 평가한다. 기존 자동 봇 실행은 사람 관측치가 아니다. |
| Q04 | 최신 대상 커밋의 원격 Web 워크플로·공개 Pages 결과 | `main` push 또는 수동 실행의 대상 SHA, Web export/배포 결과, 실제 공개 URL의 로드·입력·저장 복원을 확인한다. 로컬 성공과 과거 설정 기록만으로 현재 공개 상태를 단정하지 않는다. 실행에는 배포가 포함되므로 사용자 요청 범위에 맞춰 수행한다. |

## 과금 도입 전 보안

상세 재현 결과와 개선 완료 기준은 [과금 도입 전 데이터 변조 점검](SECURITY_REVIEW.md)에 기록한다. 실제 운영 재화·결제 API는 아직 없으며 현재 로컬 지갑을 유료 잔액으로 연결하지 않는다.

| ID | 항목과 현재 상태 | 다음 행동 / 완료 기준 |
|---|---|---|
| S01 | 로컬 지갑·원장 동시 변조와 스냅샷 권한·보상 조작을 재현했다. | 보안 점검 문서의 P0-1~P0-6을 충족한다. 서버 지갑·소유권·보상·결제 검증과 기존 로컬 재화 이전 정책을 결정하고 구현한 뒤 과금을 활성화한다. |
| S02 | 오래된 저장/인스턴스의 쓰기로 구매 상태가 되돌아가는 경로, release 개발 인자 노출과 디버그 Android 배포 설정이 있다. | P1-1~P1-4의 스냅샷 권한, release 빌드, 저장 동시성·복구와 운영 탐지를 구현한다. |
| S03 | Windows는 PE/Wine 호환 실행까지만 확인했으며 Android 앱 설치·변조 실행은 미완료다. | P1-5에 따라 Windows 실기기·Android release 비루팅/루팅 환경·Web 다중 탭·메모리/패키지 변조를 추가 검증한다. |
| S04 | Codex Security 보안 강화 설계 스킬을 적용했다. 정식 Standard 스캔은 실행 준비 검사 통과 후 대화 소유 정보 부재로 등록이 거부되었다. | 정식 스캔을 지원하는 호스트 연결 후 동일 범위의 Standard 분석을 실행하고 직접 재현 근거와 대조한다. 현재 설계 문서를 정식 스캔 완료로 표기하지 않는다. |

재현 절차는 [DEVELOPMENT](DEVELOPMENT.md), 리소스 규격은 [RESOURCE_GUIDE](RESOURCE_GUIDE.md)를 따른다. 제작 범위의 원본은 [identity-plan.json](../tools/art/identity-plan.json), 실제 등록 상태는 [identity_animations.json](../assets/art/identity_animations.json) 및 각 개체의 layout이다.
