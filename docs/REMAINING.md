# 남은 작업과 결정 사항

## 결정 대기

- 출시 제목·소개·스토리. `project-rd`와 용병 길드 테마는 내부 작업안이다.
- 사운드 방향과 최종 음원/믹싱. 임시 합성음은 출시 리소스가 아니다.

## 검증과 제작의 경계

- 첫 클리어율 5% 및 30웨이브 부근 실패는 정해진 목표다. 사람 대상 첫 플레이 표본을 수집해야 하며 자동 봇을 실제 사용자 통계로 간주하지 않는다.
- 기존 Godot 4.4.1 Android API 30 에뮬레이터에서 화면·입력·수명주기 44개 검사를 통과했다. 결과는 [ANDROID_QA.md](ANDROID_QA.md)에 기록한다. 이번 4.7.2 및 새 UI의 Android APK 재검사와 물리 Android 기기의 GPU·발열·노치·여러 해상도·제조사별 앱 종료 정책은 별도 실기기 검증이 필요하다.
- 아틀라스의 실제 완성 범위와 공유 계열/팔레트 범위는 ART_PIPELINE.md 및 아트 매니페스트에 기록한다. 87종 개별 원화는 설치했다. 용병은 개별 원화 전체를 움직이며, 적의 프레임 애니메이션은 7개 계열을 공유한다. 53종 적 각각의 고유 프레임 애니메이션 확장은 남아 있다.
- 현재 대화 이미지 도구는 모델명 선택/보고를 노출하지 않는다. 사용자 지시대로 이 도구를 사용하되 최상위 모델의 구체적 ID를 검증했다고 주장하지 않는다.
- 접근성(스크린리더·색각 보정·입력 리맵)과 실제 음향 QA는 남아 있다.

## 현재 범위 밖

출시 서명 패키지·Play Store 등록·새 클라우드 작업 복원은 사용자가 현재 고려하지 않는다고 명시했다. 내부 디버그 APK만 테스트에 사용한다. 과금·서버·영구 성장·C#은 추가하지 않는다. Web export와 브라우저 공개 플레이는 이번 사용자 요청으로 범위에 추가했다.
