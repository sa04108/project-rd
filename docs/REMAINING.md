# 남은 작업과 결정

결정 대기·구현 미완료·미검증 항목의 단일 목록이다. 현재 코드와 런타임 리소스에서 확인한 상태를 기록한다. 완료하면 항목을 제거하고 필요한 규칙·절차를 상시 안내서에 반영한다. 완료 이력·범위 밖 기능을 할 일로 누적하지 않는다.

## 결정 필요

| ID | 항목과 현재 상태 | 다음 행동 / 완료 기준 |
|---|---|---|
| D01 | 출시 제목·소개·스토리는 내부 작업안이다. | 사용자가 외부에 사용할 이름과 소개·서사 범위를 확정하면 게임 문구와 규칙 문서에 반영한다. |
| D02 | 동작 연출 줄이기 설정은 있지만 스크린리더·색각 보정·입력 재지정의 적용 범위는 확정되지 않았다. | 지원 플랫폼과 필요한 접근성 범위를 정하고, 채택한 항목의 구현·실사용 검사 기준을 정한다. |

## 구현·제작 필요

| ID | 항목과 확인한 상태 | 다음 행동 / 완료 기준 |
|---|---|---|
| A01 | 고유 적 이동은 n01–n13의 13종만 등록됐다. **나머지 40종**은 n14–n40, b10–b100(10단위), s10/s30/s60이다. | 루트가 각 개체 원화에 맞는 walk 6자세를 생성·패킹·연결한다. 53종의 실제 layout, 전체 프레임/게임 화면과 둔화·기절·정지를 검증한다. |
| A02 | 아군 공격은 u01–u34 전체 등록됐지만 **대기 34종**은 없다. 제작 계획은 idle 167ms×6이고 `import_identity.py`는 250ms×6을 출력한다. | 대기 제작 전에 도구와 계획의 타이밍을 일치시킨다. 기존 attack을 보존해 idle을 병합하고 몸 크기·발 기준점·상태 전환과 reduced-motion을 검증한다. |
| A03 | n04/n07/n11은 자세 차이는 있으나 자연스러운 양쪽 다리 교차 보행이 부족하다. 추가 후보는 미채택 상태다. | 루트가 원본을 보완하고 전체 주기의 접지·번갈아 딛기·루프를 직접 확인한다. 픽셀 차이 통과만으로 기존 원본을 교체하지 않는다. |
| A04 | 공격 이벤트와 선택·드래그 표시는 있으나 범위 피해의 모든 피격 대상, 사망·탈출, 소환·조합 결과를 구분하는 표시 보강이 남아 있다. | 실제 변경 시점의 이벤트와 짧은 연출을 연결한다. 같은 표시 간격의 생성/사망, 승리 시 정리, 재료 소비를 구분하고 보상·RNG·저장 불변을 검사한다. |
| A05 | `visual_assets.gd`는 고유 아틀라스를 지연 로드하지만 로드한 texture의 개별 해제 정책은 없다. | 살아 있는 개체·도감·잔여 효과 등의 참조를 고려한 캐시 수명 정책을 구현하고 장시간/새 게임/복원에서 누적되지 않음을 확인한다. 고유 아틀라스 soft 96MiB / hard 128MiB 목표와 실제 GPU/RSS 최고치를 함께 검증한다. |
| A06 | `assets/art/manifest.json`과 `build_manifest.py`에는 과거 전장 배경 경로와 원화 전체 이동/공유 계열 중심의 설명이 남아 있다. | 생성기와 메타데이터를 현재 정투영 배경·고유 인덱스와 일치시킨다. `identity_animations.json`의 실제 상태를 기준으로 세며 생성·연결·자동검사·시각검토를 혼동하지 않는다. |
| W01 | Web 저장은 로컬 파일 쓰기 뒤 IndexedDB에 비동기로 반영된다. 검사는 영속화 확인 후 reload하지만 일반 UI의 영속 저장 완료 표시와 즉시 종료 처리는 남아 있다. | 영속화 결과를 관측하는 UI/종료 흐름과 오류 처리를 정하고, 저장 직후 새로고침·탭 종료 사례를 브라우저에서 검증한다. 보장할 수 있는 복구 범위를 사용자에게 정확히 표시한다. |

## 검증 필요

| ID | 확인이 남은 항목 | 완료 기준 |
|---|---|---|
| Q01 | 현재 Godot 4.7.2와 최신 화면·리소스·음향을 포함한 Android APK, 물리 Android 기기 | 최신 빌드로 입력·저장·앱 중단/복귀를 재검사한다. 실제 기기의 GPU·발열·노치·해상도·제조사 종료 정책을 확인한다. 과거 4.4.1 에뮬레이터 결과를 현재 빌드나 실기기 증거로 사용하지 않는다. |
| Q02 | 최종 음악/효과음의 기기 청감·장시간 반복 피로도와 진동 | 음악/효과음 음소거, ×5 배속의 믹스, 끝 잡음·루프 이음새와 지원 기기의 진동 3조건을 확인한다. 음원 제작/연결은 완료됐으며 샘플 재선정 과제가 아니다. |
| Q03 | 초보 첫 클리어율 5%·주 실패 구간 30웨이브 목표의 사람 대상 검증 | 첫 플레이 표본과 조건을 정해 도달 웨이브·실패 원인·클리어율을 기록하고 튜닝을 평가한다. 기존 자동 봇 실행은 사람 관측치가 아니다. |
| Q04 | 최신 대상 커밋의 원격 Web 워크플로·공개 Pages 결과 | 수동 워크플로의 대상 SHA, export/브라우저 QA, 실제 공개 URL의 로드·입력·저장 복원을 확인한다. 로컬 성공과 과거 설정 기록만으로 현재 공개 상태를 단정하지 않는다. 실행에는 배포가 포함되므로 사용자 요청 범위에 맞춰 수행한다. |

재현 절차는 [DEVELOPMENT](DEVELOPMENT.md), 리소스 규격은 [RESOURCE_GUIDE](RESOURCE_GUIDE.md)를 따른다. 제작 범위의 원본은 [identity-plan.json](../tools/art/identity-plan.json), 실제 등록 상태는 [identity_animations.json](../assets/art/identity_animations.json) 및 각 개체의 layout이다.
