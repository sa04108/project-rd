# 오디오 샘플

직접 합성한 원본 샘플이며 외부 녹음을 사용하지 않았습니다. 오디오 코덱, 파형, 효과음이 반복 가능하도록 난수 시드를 고정했습니다. [샘플 듣기](audio-samples.html)에서 각 항목을 눌러 확인할 수 있습니다. 최종 선호도는 실제 게임 맥락에서 들어 본 뒤 결정해 주세요.

배경 음악은 각각 32초 길이의 서로 다른 루프입니다. `hearth_watch`(성문 곁의 불빛)는 따뜻한 현악 질감과 드문 선율, `mist_guard`(안개의 파수)는 얇은 공명과 넓은 공기감, `quiet_march`(조용한 행군)는 둥근 저음 맥박과 짧은 선율을 사용합니다. UI 효과음은 나무 선택, 가벼운 탭, 확인 차임이고, 전투 효과음은 검 스윕, 활, 둔기, 마법, 짧은 사격음입니다. 음악은 소프트 리미터로 피크를 0.15 이하로 제한하고 테마별 RMS를 약 -26 dBFS로 맞췄습니다. 전체 효과음 피크는 최대 -11.6 dBFS입니다.

| 분류 | 파일 | 형식 / 길이 | 피크 / RMS |
| --- | --- | --- | --- |
| 음악 | `hearth_watch`, `mist_guard`, `quiet_march` | 스테레오 Ogg Vorbis 56 kbps / 각 32초 | -16.7~-18.3 / 약 -26.0 dBFS |
| UI | `wood`, `tap`, `chime` | 모노 PCM16, 22.05 kHz / 0.085~0.21초 | -11.6~-15.0 / -21.9~-28.8 dBFS |
| 전투 | `blade`, `bow`, `blunt`, `magic`, `shot` | 모노 PCM16, 22.05 kHz / 0.31~0.48초 | -14.0~-16.4 / -23.0~-30.4 dBFS |

전체 파일 크기는 393,688 bytes(약 384 KiB)입니다. 파일별 길이, 실제 Ogg 디코드 PCM 기준 피크/RMS, DC 오프셋, 루프 경계 차이, 형식, 크기, SHA-256은 `assets/audio/manifest.json`에 기록했습니다. 루프의 마지막과 처음 0.48초를 겹치는 교차 페이드로 연결한 뒤 짧은 가장자리 페이드와 30ms 무음 가드를 두어 인코더 경계의 클릭을 줄였습니다. 디코드 후 측정한 세 루프의 최대 경계 차이는 0.0032입니다.

재생 샘플을 다시 생성하려면 저장소 루트에서 실행합니다. Python 3, NumPy, ffmpeg의 libvorbis 인코더가 필요합니다.

```sh
python3 tools/audio/generate_samples.py
```

음량 수치는 디지털 샘플의 측정값이며 스피커 체감 음량을 대신하지 않습니다. 실제 플레이에서 오래 들었을 때 피로하지 않은지 확인하고 세 음악 중 선호를 골라 주세요.
