- 27초 마지막 기본 탈출,30초 고정 다음 웨이브,270/300/2970초 경계,101웨이브 없음.
- 정지 사유 중첩,1/2/3/5배속 순환, 특수 해금/독립 쿨타임/만석 중 특수 소환.
- 마왕 CC, 시간만으로100웨이브 종료 없음, 사망 우선 승리, 종료 후 무변경.
- 가장 강한 둔화와 남은 효과 복귀, 기절의 늦은 만료, JSON 왕복 RNG 재현.
- 이어하기 전체 상태/정지 복원, 잘못된 필드·ID·슬롯·CC·시간·스폰 상태 거부와 무변경.
- 프로필이 먼저 저장된 중단 상황의 처치 집계 중복 방지, 종료 ID/최고 도달/클리어 분리, 개발 판 기록 제외.

## 실제 UI 입력 검사 58개

Godot viewport에 마우스 press/release/motion 이벤트를 전달했습니다. 버튼 signal을 직접 호출하지 않았습니다.
메뉴→새 게임→3회 소환→정지/배속→선택/이동/교환/잘못된 드래그→창별 정지 정책→
오버레이 입력 차단→창을 열어둔 채 구매 가능 상태 변화→설정/저장→이어하기→덮어쓰기 취소→
실제 조합 버튼→특수 잠금 상태를 검사했습니다. 캡처 파일 생성 성공 검사도 포함된58개입니다.

이는 자동 UI 시나리오이며 사람이 Android 기기를 직접 플레이했다는 의미는 아닙니다.
효과음은 Dummy 드라이버에서 듣지 않았습니다. 실제 음향/터치/백그라운드 QA는 남아 있습니다.

## 장기 플레이 프로브

전투 시간을0.5게임초 단위로 진행하되 내부 시뮬레이션은 최대1/30초로 처리했습니다.
봇은 공개된 소환·배치·조합·도박·강화·특수 소환 API만 사용했습니다.
