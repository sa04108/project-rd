Godot CLI/UI 검사 로그에 스크립트/엔진 오류가 없다. Android는 Compatibility를 유지하고 에뮬레이터 GPU를 Mesa llvmpipe로 바꿔 화면 검증을 통과했다. 앞선 SwiftShader의 [GLES 단색 실패](qa/android-gles-logic-only.json)와 [Vulkan 네이티브 종료](qa/android-vulkan-diagnostic.json)는 성공한 실행과 분리해 보존한다. 상세 재현 방법은 [Android QA](ANDROID_QA.md)에 있다. Xvfb의 V-Sync 미지원 경고와 일반 데스크톱 환경의 Android SDK 탐색 메시지는 실행 실패와 구분한다. 예상 실패 종료 코드 검사는 이전 MVP에서 확인했으며 당시 증거는 커밋 `5e4c716`의 이 문서에 있다. 이 작업에서 그 실패 주입 경로를 변경하지 않았다.

## 추가한 계약과 발견한 문제

- 일반·보스·특수의 정확히 50번째 생성, 예약 스폰, 10/100 보스 웨이브 경계에서 즉시 패배한다. 장시간 기절에도 후속 스폰을 멈춘다. 한도는 T 데이터로 조정한다.
- 패배 뒤 생성·경제·이동·배속·CC·개발 점프가 상태/RNG/revision을 바꾸지 않는다. 개발 F8의 추가 골드도 종료 후 차단했다.
- 정지 중 특수 소환 버튼에서도 결과창을 즉시 표시하고 이어하기를 제거한다. 49마리에서는 버튼에 `소환 시 패배`를 표시한다.
- 34용병, 40일반, 10보스, 3특수, 28조합의 도달 가능성과 실제 웨이브 전체 출현을 검사한다.
- 실제 `5e4c716`의 코드·데이터로 만든 [0.2 저장 fixture](../tests/fixtures/content-v0.2.0.json)의 HP/개체/다음 RNG를 보존한다. 55마리 구버전 저장은 손상으로 버리지 않고 패배로 이행한다. 메뉴→이어하기→결과→최고 웨이브/종료 ID 기록까지 UI로 확인했다.
- 도감 원화가 설명을 덮던 TextureRect 최소 크기를 고치고 34개 행의 원화 영역 검사를 추가했다.
- APK에서 제외된 테스트를 메인 스크립트가 preload하던 오류를 런타임 검사 호출로 고쳤다. Android Back은 저장 후 설정 열기/닫기로 처리하고 QA 저장소는 정상 프로필과 처음부터 분리했다.
- Android 터치 콜백에서 화면을 즉시 트리 밖으로 빼던 동작을 숨김+프레임 끝 해제로 바꿨다. `can_process` 엔진 오류가 남던 경로를 실제 `InputEventScreenTouch` UI 회귀 검사와 Android 재검사에 포함했다. 기능 44개를 통과했어도 엔진 오류가 있었던 [이전 실행](qa/android-host-before-touch-fix.json)은 실패 기록으로 보존한다.

기존 소환·이동·교환·조합·도박·강화·CC·웨이브·마왕 종료·손상 격리·중복 집계 방지 계약도 재실행했다. UI 검사는 실제 viewport 입력 이벤트를 전달하며 캡처 생성 검사도 포함한다. 사람이 휴대폰을 직접 플레이했다는 의미는 아니다.

## 밸런스의 근거와 한계

사람의 **첫 클리어율 5%, 주 실패 구간 30웨이브 부근**을 목표로 T값을 조정했다. 현재 사람 관측 수는 **0**이다. 자동 정책은 사람 표본으로 세지 않는다.

`novice_playthrough.gd`는 시작 3회 소환 뒤 5–12게임초마다 한 행동을 하며 기본 배치를 유지한다. 공개 거래 API만 사용한다. 조정용 시드에 맞춘 결과와 별도 표본을 분리한다.

| 표본 | 클리어 | 결과 파일 |
|---|---:|---|
| 조정용 시드 1–80 | 4/80 = 5% | [전체 80판](qa/novice-1-80.json) |
| 별도 시드 1001–1040 | 0/40 = 0% | [전체 40판](qa/novice-1001-40.json) |

두 표본을 합치면 4/120이며, 30–39웨이브 패배와 100웨이브 패배가 각각 27판으로 가장 많았다. **목표 난이도를 사람 기준으로 달성했다고 확정할 수 없다.** 최종 보스에서 실패가 몰리는 점도 사람 첫 플레이 관측 후 재조정할 항목이다. 현재 최종 보스 기본 HP는 350, HP 곡선은 `data/game_rules.json`에 있다.

## 아트 관찰과 남은 검증

메뉴, 전장, 도감 및 각 창의 실제 PNG를 확인했다. 6장 원화 시트의 전체 캐릭터와 추출한 넓은/복잡한 캐릭터 샘플을 확인했다. 7개 애니메이션 시트는 프레임 잘림을 수정한 후 각각 검수했다. humanoid의 작은 대기 움직임 경고와 blob의 경계 픽셀 경고는 [아트 기록](ART_PIPELINE.md)에 남겼다.

로그는 `artifacts/logs/`, GUI PNG는 `artifacts/screenshots/`, 120프레임은 `artifacts/visual/`에 있다. 대표 시각 시나리오는 `docs/screenshots/battle-art-preview-2026-10-02.png`이며 정상 플레이 밸런스 증거와 구분한다.

물리 Android 기기의 GPU·발열·노치·여러 해상도, 실제 소리, 사람 첫 플레이 통계는 남아 있다. 출시 서명 패키지와 새 클라우드 작업 복원은 현재 범위 밖이다.

## 위임 기록

아트/Android는 `gpt-6-luna`, reasoning `medium`을 요청한 기존 작업자를 재사용했다. 저장·종료·수명주기 독립 리뷰는 `gpt-6.1-sol`, reasoning `high`를 요청한 작업자가 수행했다. 동시 작업자는 최대 2명이다. 실제 실행 모델/effort 및 루트·작업자·재시도의 사용량/비용은 제공되지 않아 알 수 없다. 이미지 도구도 모델 식별자를 노출하지 않아 최상위 이미지 모델을 검증했다고 주장하지 않는다.
