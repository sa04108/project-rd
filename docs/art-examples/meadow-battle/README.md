# 맑은 초원 전투 적용 화면

이 파일들은 생성형 시안이 아니라 Godot 4.7.2의 실제 렌더링 결과다.

- `battle_placed.png`: 터치·드래그 회귀 시나리오의 전장. 하단 버튼 위치를 유지하고 선택 정보만 표시한다
- `effects-allies.png`: 34개 용병의 무기·속성별 공격 표현 및 축소 동작 표시
- `effects-enemies.png`: 53개 적의 재질별 명중·소멸 표현. 적 공격 기능은 추가하지 않는다

테스트용 전투이며 전체 100웨이브 밸런스나 실제 Android 기기 플레이를 검증했다는 뜻은 아니다. 주변 풍경과 지형을 분리하고, 새 위쪽 시점의 풀·흙 재질을 정사각 격자와 일정 폭의 축 정렬 사각 통로에 그린다. 생성 도구의 임의 배치로 판정 좌표를 바꾸지 않는다.

최신 캡처는 1칸 폭 흙길, 자연스러운 재질 경계, 평상시 격자 숨김 및 상단 반투명 알림을 포함한다. `menu.png`는 전투 HUD와 같은 스타일로 정리한 메인 화면이다. 표시 이름은 설정값이며 저장 식별자를 바꾸지 않는다.
