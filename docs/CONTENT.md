# 콘텐츠 0.3.0

사용자 결정에 따라 용병 34명·일반 적 40종·보스 10종(마왕 포함)·특수몬스터 3종을 등록했다. 출시 제목과 서사는 미정이며 이름과 역할은 플레이용 작업안이다. 기존 ID와 1성 소환 풀은 유지했다.

용병 성급별 수는 6/10/12/6명이며 28개 조합법으로 전원 도달 가능하다. 2·3성 도박 풀은 해당 성급 전체다. 공유 계열/팔레트와 실제 개별 아트 제작은 별도이며 `assets/art/manifest.json`과 ART_PIPELINE.md에 실제 범위를 기록한다.

## 조합

모든 조합은 정확한 ID와 수량을 소비한다. 2성은 1성 두 명, 3성은 2성 두 명, 4성은 명시된 세 명이다.

| 결과 | 재료 |
|---|---|
| 왕실 창기사 | 길드 검사 ×1 + 숲길 궁수 ×1 |
| 룬 저격수 | 숲길 궁수 ×1 + 견습 마도사 ×1 |
| 전쟁 북장이 | 수도사 ×1 + 길드 사제 ×1 |
| 설원 사냥꾼 | 견습 마도사 ×1 + 늪지 약제사 ×1 |
| 철갑 수호자 | 길드 검사 ×2 |
| 폭풍 검무가 | 왕실 창기사 ×1 + 룬 저격수 ×1 |
| 대현자 | 룬 저격수 ×1 + 전쟁 북장이 ×1 |
| 황금 고블린 | 설원 사냥꾼 ×1 + 철갑 수호자 ×1 |

| 은빛 성기사 | 왕실 창기사 ×1 + 철갑 수호자 ×1 |
