# 초기 콘텐츠 범위

콘텐츠 정의는 `data/`의 JSON 파일에 있으며 버전은 `0.2.0`이다. 이 단계에서 실제 등록한 플레이 가능 용병은 16명(1성 6명, 2성 5명, 3성 3명, 4성 2명), 일반 적 8종, 보스 10종(마왕 포함), 특수몬스터 3종이다. 이는 명세의 미래 콘텐츠 초안인 34용병·40일반·10보스·3특수 전체 제작을 뜻하지 않는다.

용병과 적은 인간형, 중량형, 사족형, 다족형, 부유형, 덩어리형, 용형의 공유 아트 계열을 참조한다. 정의의 `family`와 `color`는 시각 리소스 연결용이며 전용 아트나 리그 제작 완료를 의미하지 않는다.

초기 전투 수치, 소환·도박·강화 가격과 확률은 5개 시드의 자동 플레이로 클리어 가능성을 확인한 초기 튜닝값이다. 고정값(F), 구현 해석(I), 작업 기본안(D), 튜닝(T)은 `data/game_rules.json`에서 분리했다. 특수몬스터 해금값은 해당 웨이브 완료 기준이다. 적 체력 성장 계수는 규칙의 T 값이며 기본 적 체력에 웨이브별로 적용한다.

레시피는 정확한 용병 ID와 수량을 사용한다. 각 2성 결과는 1성 두 명, 각 3성 결과는 2성 두 명, 각 4성 결과는 3성 재료를 포함한 세 명 조합이다. 1성 용병은 소환으로 획득한다. 모든 등록 용병 등급은 조합 결과 또는 1성 소환을 통해 도달 가능하며, 도박 풀에서도 해당 등급의 전체 카탈로그를 사용할 수 있다.
