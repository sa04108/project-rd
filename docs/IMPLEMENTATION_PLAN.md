# MVP 구현 계약

- Godot 4.4.1 / GDScript / Compatibility / 720×1280 세로 UI.
- 원본 명세는 MVP_SPEC_v0.2.md. F값은 데이터에서 보존하고 D/T만 기록 후 조정한다.
- simulation.gd가 30Hz 고정 소단계, 거래, 웨이브, 승패를 소유한다. 렌더·입력·저장은 분리한다.
- 정수 칸 번호는 `열*6+행`. 개체 ID는 판 안에서 단조 증가. 적 진행도는0..26이며 되감지 않는다.
- 신규 게임은150골드/20목숨/용병0명. 자동 시작과 수동 일시정지, 1/2/3/5배속.
- 콘텐츠는34용병/40일반/10보스(마왕 포함)/3특수와28개 조합법. 전체 카탈로그를 데이터로 정의하고87개 개별 원화와7개 공유 애니메이션 계열을 관리한다.
- 루트가 시뮬레이션·저장·UI·통합 검증을 소유. 작업자는 Android 검증과 에셋 파이프라인을 나누어 담당하고 저장·종료 조건은 독립 리뷰한다.
- 필수 검증: import, 계약 테스트, 메인 smoke, 정상/실패 종료 코드, 저장 복구·종료 경합, 실제 GUI 입력과 PNG 확인. 터치 기기/Android 수명주기는 데스크톱 검증과 구분한다.
- 첫 커밋은 사용자 AGENTS.md. 기존 환경설정 변경은 보존하고 MVP 커밋에 섞지 않는다.
