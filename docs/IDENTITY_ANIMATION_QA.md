## 구현

개별 정체성 아틀라스를 필요한 순간에 읽는다. 공격은 준비 180ms와 타격 이후 480ms에 연결하며 첫 즉시 공격에서는 준비 프레임을 건너뛴다. 이동은 실제 진행 거리를 사용해 감속·기절·정지에 맞춘다. 기절 시 공용 몸체로 돌아가지 않는다. 기존 공격 판정, RNG, 쿨타임, 저장 스키마는 변경하지 않는다. 각 셀은 256×256이며, 동일한 캐릭터의 한 행 전체에 같은 배율과 발 기준점을 적용한다.

## 후속 UI·경로·오디오 통합 검증

원격 main `daef2b6`의 오디오 작업을 보존해 합쳤다. 전투 경로는 폭 1칸, 중심선 한 변 7/전체 28단위이며 사거리도 같은 좌표를 사용한다. 카탈로그 이동 시간은 유지하고 이전 저장의 26단위 진행도를 주회 비율로 복원한다. 배치용 격자는 드래그 중에만 표시한다. 풀·흙 경계는 셰이더로 부드럽게 섞고, 공통 안내는 최상단 반투명/입력 통과로 표시한다.

통합 headless 검사: 게임 계약39, 오디오209, HUD244와 생명주기·애니메이션·효과·포인터·스모크 통과. 실제 Compatibility UI308 검사 통과. 메인 화면 제목은 `presentation/display_name`만 읽고 기존 `application/config/name`은 그대로 유지하므로 표시 이름 변경이 영속 저장 경로를 바꾸지 않음을 검사했다. 메인 버튼으로 이동할 때 저장 실패는 전투 화면을 유지하고, 저장 성공 후 이어하기는 전체 스냅샷을 보존한다.
