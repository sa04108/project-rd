# 개별 프레임 보강: 첫 번째 검증 묶음

전체 제작 계획은 `RESOURCE_UPGRADE_PLAN.md`를 따른다. 이 문서는 **15종, 15개 동작 행, 90개 새 자세**까지의 첫 검증 결과이며 전체 완료 보고가 아니다.

## 대상

- 공격 12종: u01–u06, u17–u22
- 이동 3종: n01–n03
- 다른 개체의 제작 원본은 작업 중이며, 첫 묶음의 검증/커버리지에 포함하지 않는다

## 구현

개별 정체성 아틀라스를 필요한 순간에 읽는다. 공격은 준비 180ms와 타격 이후 480ms에 연결하며 첫 즉시 공격에서는 준비 프레임을 건너뛴다. 이동은 실제 진행 거리를 사용해 감속·기절·정지에 맞춘다. 기절 시 공용 몸체로 돌아가지 않는다. 기존 공격 판정, RNG, 쿨타임, 저장 스키마는 변경하지 않는다. 각 셀은 256×256이며, 동일한 캐릭터의 한 행 전체에 같은 배율과 발 기준점을 적용한다.

## 실행한 검사

- `python3 tools/art/test_import_identity.py`: 4개 패킹 계약 통과
- `bash scripts/verify.sh`: 가져오기, 기존 36개 계약, 생명주기, 새 7개 애니메이션 계약, 실행 검사 통과
- 실제 클라우드 데스크톱의 Godot 4.7.2로 `tests/ui_scenario.gd`: 260개 통과
- 실제 화면의 `tests/identity_visual_scenario.gd`: 15종/15상태, 17개 캡처, 787개 검사 통과. 모든 행에서 실제 렌더링된 여섯 프레임이 서로 다르고 발 기준점/경계/정지/축소 동작 및 불변 상태 검사 통과
- `bash scripts/web-export.sh artifacts/web`: Web 내보내기 통과
- 로컬 Web 게임을 Node 26.10.0 + Playwright 1.60.0 + 시스템 Chromium 154.0.8037.57로 검증: 전투 입력, 속도, 배치, 패널, IndexedDB 저장, 메뉴/계속, 새로고침, 데스크톱/모바일 터치/넓은 화면 및 공개 모드 검사 통과. 브라우저 오류 없음

실제 화면 캡처도 확인했다. 검토 원본은 `docs/art-generation`에, 실행 시 생성되는 보고서/캡처는 무시되는 `artifacts/identity-visual`, `artifacts/identity-web-qa`에 있다.

## 남은 범위와 실행 환경 구분

- 나머지 공격/이동과 34종 대기 동작, 상태/처치/탈출 연출은 계속 제작해야 한다
- 이 변경은 Playwright 의존성 업그레이드를 포함하지 않는다. 저장소의 기존 1.57.0은 최신 Node의 브라우저 설치와 별도 호환성 문제가 있으며, 1.60.0 수정은 별도 작업이다. 위 Web 검사는 설치된 1.60.0을 사용한 실제 결과이며 기존 CI가 통과했다는 주장이 아니다
- main 푸시에서만 자동 워크플로가 시작되므로 작업 브랜치에는 자동 CI가 실행되지 않는다
- 공개 Pages 배포 성공, 물리 Android 장치 검사, 100웨이브 인간 밸런스 검증은 이 결과에 포함되지 않는다
- 이미지 백엔드의 모델 ID는 노출되지 않는다. 생성 성공만으로 최고 등급이나 완성 품질을 주장하지 않는다
